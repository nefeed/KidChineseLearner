## 重现命令

先运行 `npm run dev`，然后在允许自动浏览器控制的独立环境运行：

```sh
npx playwright test tests/zoo.spec.ts --reporter=line
```

默认使用已安装的 Chrome、`http://127.0.0.1:5173`。可通过 `PLAYWRIGHT_CHANNEL` 和 `ZOO_TEST_URL` 指定测试浏览器及地址。静态用例可单独运行，无浏览器操作：

```sh
npx playwright test tests/zoo.spec.ts --grep 静态 --reporter=line
```
