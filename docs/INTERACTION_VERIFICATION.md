# 操作提示与语音一致性验证

2026-10-02。本轮从用户反馈的“跟着星星写字，但看不到星星”出发，核对首页、课程目录、汉字六阶段、诗词六阶段、动物园与家长小屋的提示、操作目标和完成条件。

## 已修复的问题

| 页面 | 原问题 | 当前行为 |
| --- | --- | --- |
| 学写字 | 提示有星星，画面只有圆点和箭头 | 五角星沿当前笔画移动；手指描写时标记对应进度，抬手后可续描 |
| 笔顺示范 | 提示让孩子跟画，但示范期间不能输入；停止仍播开始提示 | 示范时明确先看，结束后再描写；停止不再播开始提示 |
| 书写状态 | 重描可能仍在示范，换字可能沿用旧笔画，完成回调重复 | 重描与换字重置对应状态；一次完成仅通知一次 |
| 擦字卡 | 喇叭尚未出现就提示听句子；父容器捕获指针后，普通点盖板无效 | 提示和操作都先揭开八块盖板，支持点按或拖擦，再听句子、选词、选意思 |
| 窗、瓜小游戏 | 拉窗帘却说打开窗；已有两块瓜却提示切成两半 | 文案分别对应拉开窗帘、分开两块瓜 |
| 种土、找虫、行进 | 提示盖土、叶子等不存在的对象或动作 | 文案对应种入土坑、找到三只虫、依次点标记 |
| 认字、听声音、词义小游戏与跟读 | 点击播报即算听过 | 播放完整成功后才确认；取消或过期回调不计入进度 |
| 静音学习 | 声音关闭时仍要求听完，可能无法继续 | 显式提供看句子、看图提示、阅读或家长确认，不伪造听音记录 |
| 汉字测验 | 题目提到实际不存在的小兔 | 明确提示听词语、找其中的字 |
| 诗词朗读 | “正在听诗”按钮实际可暂停，含义混淆 | 忙碌状态按钮禁用，独立“暂停”按钮执行暂停 |
| 诗词生活练习 | 重进已完成练习，步骤仍显示未完成；确认分享后又邀请分享 | 恢复已完成状态，播报已尝试并分享的反馈 |
| 诗句排序 | 提示听前一句，却播下一句 | 说明正在听接下来该接的诗句 |
| 首页奖励入口 | “看看奖励”打开照顾页 | 直接进入邀请函 |
| 动物园领取反馈 | 指向不存在的“移动”按钮 | 提示实际存在的“照顾朋友”和“布置动物园” |
| 儿童档案入口 | “管理儿童档案”验证后停在学习节奏页 | 验证后直接显示儿童档案 |
| 目录拼音搜索 | 承诺搜拼音，却不接受无调输入 | 支持带调、无调、大小写以及 `nv` / `nü` |
| 备份与创建档案 | 取消导入后仍要求确认；创建成功反馈出现在备份页 | 取消反馈与当前操作一致，创建反馈留在档案页 |

书写的起点、箭头、真实笔画坐标与判定容差保留。星星不拦截手势，画布边缘的星形图案会向内微调以完整显示；儿童的描写坐标和笔顺数据不变。降低动态效果设置下，标记停在起点，仍保留箭头方向。

## 语音修复

- 过去的音频计划仅用引号正则扫描，遗漏了一些静态提示，也没有展开种树、喂食、颜色与动物园的动态句子。这些普通操作会转为设备系统声音。现在采用语法树提取，并从共享词汇和动物园播报函数展开有限文本，纳入统一的本地 Kokoro 女声录音。
- 动物的自定义名字保留在界面，录音称呼“这位朋友”；改名确认播报“新名字已经记住啦”。即时反馈与“再听一次”使用同一份播报，避免名字触发不同的系统声音。
- AAC 播放速率在开始前固定为家长档位对应速率的 `0.96` 倍，保留音高。播放中不反复改速率，末字也不淡出。默认句后停顿为 260 毫秒；诗行连续朗读保留显式 240 毫秒停顿。
- 剩余不超过 650 毫秒时，新提示等待当前录音和停顿完成；只保留最新一次待播请求。退出、静音、切后台仍立即停止，并取消待播内容。
- WebKit 的真实 AAC 对照中，反复改速率会扰动媒体时钟。最终采用固定速率，两引擎均按原生 `currentTime`、`ended`、下一段 `play` 和完成 Promise 验证。

## 自动回归与边界

用例保存在 `tests/ipad-touch.spec.ts`、`tests/lesson-prompts.spec.ts`、`tests/prompt-navigation.spec.ts`、`tests/narration-browser.spec.ts` 和 `tests/narration-plan.test.ts`。全页检查沿用 `tests/ipad-layout.spec.ts`，覆盖 iPad Air 5 横竖屏与 Safari 可用区域；测试先测量边界和滚动尺寸，再操作控件。

课程完成条件测试使用真实组件和可控的播报 Promise，分别验证成功、取消、迟到和静音。AAC 专项使用真实文件与原生媒体事件；动物园播报专项在完整 App 中检查原生播放和本地音源请求。所有测试使用隔离浏览器和合成档案，不改动日常儿童进度。

最终数量、命令、源码摘要与部署摘要记录在 `scripts/verification/prompt-voice-audit.json`；全量录音文件、文本计划和读音配置审计见 `scripts/verification/audio-audit.json`。这轮验证没有接入实体 iPad，也不代表对全部录音做过人工听审。
