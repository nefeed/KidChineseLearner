# 研究记录

检索日期：2026-10-01。只用开发者和教育主管部门一手介绍作产品/教育方法依据。

## 洪恩方法对照

当前公开产品有 1800 字；较旧 Google Play/活动介绍仍为 1300 字。本项目数量按用户明确要求为 1000 字，不把旧数量当最新事实。

| 公开方法 | 字游小岛实施 |
|---|---|
| 玩：生活情境的互动 | 主题动作游戏，引出具体字义 |
| 认：字形、字义、字音 | 字卡、拼音、释义、词句、相关图景 |
| 练：听音找字、辨形等 | 多种随机选择题，错误重试 |
| 写：初步运笔与笔画 | 真实笔顺动画和按序描写 |
| 说：单字扩展词句 | 跟读常用词句，亲子表达确认 |
| 每日回顾/阶段检测 | 单字最终过关、间隔复习 |
| 分阶、生活主题 | 具体事物先行，生活表达到阅读 |
| 家长管理 | 档案、时长、声音、进度、备份 |

来源：[洪恩官网](https://www.ihuman.com/shizi/)、[开发者 App Store 介绍](https://apps.apple.com/cn/app/id1139733348)。未取得洪恩源代码、付费课程内容或全流程实际体验；实施公开方法并使用原创素材。

## 幼儿路径

教育部指南支持从生活情境和共读中产生文字兴趣。先听懂、看懂、说出来，再认识与事物相连的字形，逐步接触词句与文学韵律。笔顺体验不以精确成人书写为目标，3 岁使用宽容轨迹与家长陪伴。长诗词设较高难度，供成长后的持续学习。

来源：[教育部说明](https://www.moe.gov.cn/jyb_xwfb/s271/201210/t20121015_143257.html)、[指南 PDF](https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/jyzt_2015nztzl/xueqianjiaoyu/yaowen/202104/W020210820338905908083.pdf)。

必要性边界：早期文字接触有助于阅读兴趣与语言表达，但不能据此声称 3 岁必须学完 1000 字或背 300 首。课程通过具体事物、亲子交流、自由探索和短时间安排培养兴趣。
