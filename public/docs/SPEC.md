# 字游小岛 · 产品与验收规格

版本：2026-10-01。目标：从 3 岁亲子启蒙开始，提供逐字学习的 1000 字长期课程、唐诗宋词 300 首课程，学习奖励用于建设可照顾的个人动物园。所有档案在本机持久保存。

## 1. 研究与设计依据

- 洪恩官网：https://www.ihuman.com/shizi/ ，2026-10-01 阅读。字形字义动画、生活主题、记忆曲线复习、阶段检测、由单字走向词句与阅读。
- 洪恩开发者 App Store 介绍：https://apps.apple.com/cn/app/id1139733348 ，同日阅读。当前公开教学链为“玩、认、练、写、说”，三个层级为识字启蒙、生活常用、进阶提升；家长可设时长、每日目标、环节等。
- 教育部《3—6 岁儿童学习与发展指南》说明：https://www.moe.gov.cn/jyb_xwfb/s271/201210/t20121015_143257.html 。3—4 岁重点是倾听表达、画面理解与阅读兴趣，在生活和阅读中萌发文字兴趣，避免机械强化训练。
- 1000 字不是官方规定的“3 岁必须掌握”指标；300 首也不是 3 岁背诵要求。保留用户要求的完整长期内容量，按兴趣和理解逐步推进，默认每天 3 字、每次 10 分钟，支持随时休息。
- 严格对照洪恩公开的教学流程和进阶方法实施；界面、角色、美术、互动与动物园为原创，项目不声称为洪恩官方产品。缺少实际体验的细节不能凭营销文字声称复刻。

## 2. 信息架构

主入口是明亮的海岛学习地图，包含：识字冒险、诗词花园、我的动物园。常驻声音开关、档案选择、星星奖励与家长区。学习操作有大图标和语音引导，触摸目标不小于 56px；电脑、平板、手机均可用。

识字地图：1000 个不同常用简体字，分 100 课，每课 10 字；前 100 字优先具体事物、身体、家人、数字、自然，随后生活表达、阅读进阶。显示未学/进行中/学会/待复习，自动定位上次学习的字；可在家长陪同下选择字库中的任意字。

诗词地图：300 首不同的唐诗与宋词，短篇启蒙优先；按自然、季节、亲情、想象、生活、情绪等主题与难度筛选。幼儿路线避开长篇；长篇以亲子赏读进入，不强制背诵。

## 3. 每个汉字的关卡（全部 1000 字必须覆盖）

1. **玩**：与字义相关的点按/拖动/收集/分类操作，将具体事物变为汉字。场景说明用简单中文，语音提示；不同主题有不同互动，不能仅换字文本。
2. **认**：汉字、带声调拼音、幼儿可理解的中文释义、常见词语、生活例句；点字读字、点拼音听音节，展示声母韵母声调指导，字形与事物关联动画。
3. **练**：听音找字、看字选含义，随机干扰项；答错温和提示且不得记为完成，练习成功才推进。
4. **写**：真实规范笔顺逐笔动画、当前笔画提示；手指/鼠标沿中线描写，有方向/覆盖判定，按笔顺逐笔完成。3 岁允许看示范后亲子体验，但不能把单次点击当作写完整字。
5. **说**：词语与短句跟读，先听后读；没有可靠语音识别时由陪同成人确认朗读，不谎称自动评分。应扩展为实际生活应用。
6. **过关**：至少包含读音、字义/字形的独立题；达到标准才获得学会状态、星星与动物奖励。中途退出保存每一阶段与描写进度。

所有字必须有合法拼音、中文释义、例词例句、真实笔画路径与中线数据。数据缺失时显示真实缺失，不用假笔顺代替。多音字使用当前词语语境读音；有编辑确认的语境校订记录。

复习：首次过关后按 1/3/7/14/30 天安排，答错缩短下一次间隔；重复过关不能重复领取首次奖励；“学过”不等于保证实际掌握。

## 4. 每首诗词的课程（全部 300 首必须覆盖）

- 全文、作者、朝代、带声调逐字拼音；按句播放与慢速跟读，正在读的行高亮。
- **听与看**：匹配诗词意象的动画场景，点物听词。
- **诗里的故事**：通俗解释作品内容、作者的时代与可考写作背景。区分史实、推测与儿童想象，不能把未知的具体写作时间地点写成事实。
- **今天也能做**：结合日常现实活动与公共生活，例如观察月亮、记录天气、节约粮食、问候亲人、爱护环境。若提及最新事件须有日期来源；不编造时事。
- **游戏理解**：句子/图景匹配、意象选择或排序，提供理由。
- **背诵练习**：整句→缺字→隐去整句递进提示；拼句排序与填空，有明确答案；朗读/背诵由家长确认或经验证的识别确认。
- **过关**：完成理解任务和背诵练习才获奖励，完整记录阶段与复习计划。诗词奖励动物或动物园建筑，首次奖励幂等。

## 5. 动物园

- 首次识字/诗词过关得星星；每 10 字解锁一只动物，每 5 首诗词解锁一个建筑/动物，整体奖励覆盖长期课程。
- 奖励区展示下一目标与已领取状态，用户主动领取；领取后持久保存。
- 动物有原创卡通形象、名字、栖息地、饱腹、清洁、亲密度；不学习也不会生病、死亡或惩罚孩子。
- 喂食：选择合适食物，拖/点送给动物，咀嚼动画、状态改变、词语语音；不适合的食物有解释。
- 洗澡：拖动泡泡刷去污渍，水滴/泡泡动画，完成后更新清洁与亲密度。
- 建设：获得建筑后放置到格子，可移动动物与建筑、命名动物园，形成独特布局并保存。

## 6. 声音与动画

普通话字音、词句、诗词行、提示发声；拼音按钮实际播放汉语音节并提供拆音/声调引导。优先本地音频，系统中文 TTS 作为可见的后备；如果没有中文声音，应明确提示家长安装，不能静默视为正常。

动画使用 SVG/CSS transform/opacity，页面切换、选中、答题、笔画、动物动作持续平滑，遵守 prefers-reduced-motion。长文本及诗词播放可停止；切换页面取消旧语音。

## 7. 本地档案与恢复

每名儿童有独立 UUID、名字、头像、识字/诗词阶段、过关记录、复习、星星、奖励、动物状态、布局、设置、最后活动。操作后即保存，刷新/关闭重开同一地址可恢复。保存失败显式提示，保留备份；解析损坏不能覆盖旧档案。支持 JSON 导出/导入、版本校验与家长区操作；不因切换儿童串档，不重复发奖。

## 8. 验收矩阵

| 要求 | 证据 |
|---|---|
| 研究后规格 | 本文件、RESEARCH.md 的一手来源与方法对照 |
| 1000 字真实内容 | 数据审计：数量/唯一性/拼音/释义/例句/真实笔顺全部存在；内容逐项校订 |
| 所有字多阶段可玩 | 通用关卡引擎、分主题互动、随机抽样和全部数据契约测试 |
| 逐字过关 | 未完成/答错不得过关，阶段恢复，奖励幂等测试 |
| 300 首唐诗宋词 | 数量、作者、原文、拼音、背景、解释、现实活动审计及逐首编辑审校 |
| 诗词理解与背诵 | 多阶段完成流程、正确/错误分支、音频与读行测试 |
| 动物园奖励与互动 | 领取/重复领取、喂食/错误食物、洗澡、布局恢复测试和浏览器实测 |
| 文字与拼音发声 | 实际中文声音验证、无声音后备提示、播放取消与跟读流程 |
| 本地多用户恢复 | 多档案隔离、刷新恢复、导入导出、存储损坏/失败测试 |
| 流畅、适合幼儿 | 桌面/触屏尺寸实测、无控制台错误、触摸笔顺与动物互动、动画与减少动画 |

**完成标准：每一行均有范围相称的证据。库的数量、一次 build 或一个示范字不能单独证明目标完成。**
